# React Tic-Tac-Toe Game 🎮

Official React tutorial concepts par mabni aik modern Tic-Tac-Toe game jo React, Vite aur CSS ke sath bani hai.

## ✨ Features
- **White (Light) Theme by Default**: Clean, modern aur soft white cards ke sath UI.
- **Adjustable Theme & Dark Mode**:
  - ☀️ **White / Light Mode**
  - 🌙 **Dark Mode**
  - 🎨 **Adjustable Accent Colors**: Indigo, Ocean Blue, Emerald Green, Rose, Purple
  - Browser me user ki preference `localStorage` me save rehti hai.
- **Components & Reusability**: Reusable `Square` component.
- **Props & State**: Parent-to-child data flow aur `useState` hook.
- **Lifting State Up**: Centralized state management.
- **Game Logic**: Winner detection, winning row glow effect aur draw detection.
- **Time Travel / Move History**: Kisi bhi past move par jump back karne ki sahulat.

## 🚀 How to Run

1. Development server chalayein:
   ```bash
   npm run dev
   ```

2. Browser me open karein:
   `http://localhost:5173`
